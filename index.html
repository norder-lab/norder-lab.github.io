About Me

情報系 / データサイエンス専攻の大学生です.

2019年に Java のオブジェクト指向からプログラミングを始め, そこで培った設計思想をベースに現在は Rust や Python を主軸として開発を行っています.

AI や時代の変化によって扱う技術領域が大きく移り変わっても, 常に好奇心を持って柔軟に適応し続けられるエンジニアを目指しています.

このアカウントでは, 自作ツール(TUI / GUI)や大学の課題で制作したプロダクト, 普段の開発環境の設定ファイルなどを公開しています.
また, Qiita では個人開発の知見や技術検証, 学びの備忘録などを発信しています.

Design Stance

特定の OS やマシンスペックに依存しない「疎結合でシンプルな設計」を重視しています.
マウスを介さずキーボード完結で扱える軽快な操作感を追求しており, 自作の TUI ツールには原則として Vim キーバインドを標準実装しています.

Language Roles & Vision

  • Java 2019年に初めて触れた言語. 設計思想の基盤であり, 複雑な状態管理や安定した動作が求められるゲーム開発の主軸.
  • Rust メモリ安全性と高速性が求められる, 信頼性の高い TUI/CLI ツール開発の主軸.
  • Python データ分析, 機械学習, および豊富なエコシステムを活用したプロトタイピングの主軸.

今後は機械学習モデルと実用的なプロダクトを掛け合わせたツール開発にも挑戦し, 技術領域の変化に好奇心を持って柔軟に適応し続けます.
